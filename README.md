# Hotel Management System

## 1. Giới thiệu
Dự án quản lý khách sạn được xây dựng bằng Java, áp dụng lập trình hướng đối tượng (OOP).

## 2. Chức năng chính
- Quản lý phòng
- Quản lý khách hàng và nhân viên
- Quản lý đặt phòng và trả phòng
- Quản lý dịch vụ và hóa đơn
- Thống kê doanh thu

## 3. Phân công thành viên
- TV1: Quản lý phòng (Room Module)
- TV2: Quản lý khách hàng và nhân viên (Person Module)
- TV3: Quản lý đặt phòng (Booking Module)
- TV4: Quản lý dịch vụ và hóa đơn (Service & Invoice Module)
- TV5: Tích hợp hệ thống, giao diện và thống kê (Integration & Statistics)

## 4. Công nghệ
- Java
- OOP
- GitHub
